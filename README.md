# Option-Pricer-Greeks----Trinomial-Tree
Pricer d’options européennes et américaines en Python par arbres binomial et trinomial, piloté depuis Excel. Dividendes discrets, pruning (temps ÷5), construction backward (mémoire ÷70), méthode BBS (erreur &lt; 0,001 €) et grecques par différences finies. Projet M2 EIF, Paris-Dauphine.
